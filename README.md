# Danskværkstedet 5.D

Interaktiv danskportal for 5.D med differentierede opgaver i læsning, stavning, grammatik, fortolkning, tekstfremstilling og mundtlighed.

- Tre niveauer i hver aktivitet
- Vejledende starttest med forslag til øveområder
- Faglig feedback, strategihjælp og badges
- Originale tekster og opgaver, ikke kopier af forlagenes betalingsmaterialer
- Fremskridt gemmes kun lokalt i browseren

Bygget med inspiration fra klassens ugeplan og Fælles Måls fire kompetenceområder i dansk efter 6. klassetrin.

Åbn som GitHub Pages: https://hartelius-hue.github.io/dansk5D/
